# Deferred simulator work versus permanent non-goals

Remaining Irvine32 routines such as `DumpRegs` and `DumpMem`, plus unimplemented Irvine32 `INVOKE` forms including `INVOKE WriteBin`, remain deferred simulator work. WinAPI execution, PE loading/linking, host filesystem access, native process behavior, Windows process emulation, and full x86 emulation are permanent product non-goals.
